# meokdo

맛집 기록이 쌓일수록 **시군구 단위 지도가 진하게 칠해지는** 개인 맛집 일기 웹앱.
가게를 기록할수록 내가 다녀온 지역이 색으로 채워진다.

## 스택

- **Next.js 16** (App Router) + **TypeScript** + **React 19**
- **Supabase** — Auth(카카오 OAuth) · Postgres(RLS) · Storage
- **MapLibre GL** — 시군구 GeoJSON 폴리곤 choropleth (지도 타일 없이 우리 경계를 직접 색칠)
- **카카오 로컬 REST API** — 가게 **키워드 검색에만** 실시간 사용(응답 미저장)
- **Turf.js** — 좌표의 시군구 판정(저장 시 1회) · **mapshaper** — 경계 단순화

## 핵심 규칙

- 가게 하나에 기록 1개. 다시 가면 기존 기록을 수정한다.
- 칸 색은 칸 안에서 기록한 **서로 다른 가게 수**로 정한다 (단계 0~5: 0 / 1~5 / 6~10 / 11~15 / 16~20 / 21곳~).
- 기록 필수: 가게(상호명)·별점(1~5)·한 줄 메모. 사진(최대 5장)·메뉴는 선택. 방문 날짜 기본 오늘.
- 사진은 업로드 전 클라이언트에서 리사이즈(긴 변 ~1280px) + 메타데이터 제거.
- 모든 테이블에 RLS — 본인 행만 읽고 쓴다.

## 데이터 저장 원칙 (카카오 약관 준수)

카카오 로컬 API 응답(상호명·주소·좌표)은 **저장하지 않는다**. 대신:

- **상호명** = 사용자 입력(검색 결과로 자동완성하되 사용자가 수정·확정 → 사용자 콘텐츠)
- **region_code** = 좌표로 서버에서 Turf 판정 후 저장(좌표 자체는 폐기)
- **카카오 검색** = 실시간 프록시로만 사용, 응답을 DB에 쓰지 않음

→ DB에 들어가는 카카오 출처 필드는 0개. 배경은 `docs/DECISIONS.md` #6.
