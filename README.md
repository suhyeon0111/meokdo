# 오늘 점심 지도 (가칭)

오늘 점심 메뉴를 정하면, 그 선택이 모여 **"오늘 우리 동네는 뭘 먹었나"** 지도가 칠해지는 웹 서비스.

> 들어오면 동네 사람들이 오늘 많이 먹은 메뉴를 보고 → 메뉴를 고르면 근처 가게가 뜨고 → "이걸로 결정"을 누르면 그 선택이 지도에 한 표로 더해진다.

## 원칙
1. **회원가입·로그인 없음.**
2. 서버에 개인 식별정보를 남기지 않는다. 저장은 "날짜·시군구·메뉴 종류별 표 수"뿐.
3. 카카오에서 받은 가게 정보는 화면에 보여주기만 하고 저장하지 않는다.

## 스택
- **Next.js 16** (App Router) + **TypeScript**, Vercel 배포
- **카카오 Maps JS SDK (services)** — 근처 가게 검색 + 좌표→시군구 변환 (클라이언트, 저장 없음)
- **d3-geo + 단순화 시군구 GeoJSON → SVG** — 점심 지도 (카카오 타일 미사용)
- **Supabase Postgres** (auth 미사용) — `vote_counts` / `event_counts` 집계만
- 레이트리밋: 만료 카운터(Upstash 권장) — IP는 DB에 남기지 않음
