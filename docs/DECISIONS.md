- **추천: A**
- **결정 기준**
  - 카카오 FAQ가 로컬 API 응답의 별도 저장을 허용하지 않음 → B는 `region_code`를 DB에 저장하는 본 설계와 충돌.
  - 2026-07 행정구역 개편(인천 2군·9구, 전남광주통합특별시)을 **우리가 직접 반영**해야 함 → 경계 데이터를 손에 쥐는 A가 유리.
  - 리스크: 전국 판정용 폴리곤 런타임 로딩 비용 → bbox prefilter + 모듈 캐시로 완화. 그래도 느리면 **PostGIS `ST_Contains`로 전환**(판정 인터페이스만 교체, 저장 스키마 불변).
- **결정 기한**: 2026-10-26 (Day 3, 판정 정확도 스파이크 전).
- **지연 시 영향**: 경계 전처리(A1)·판정(A3)·지도(A2)가 모두 막힘. Week 1 전체 지연.

## #4. 로그인 방식 — 카카오 OAuth vs 이메일 매직링크

- **선택지**
  - (A) **카카오 OAuth** (Supabase 내장 provider)
  - (B) 이메일 매직링크
- **추천: A (카카오 OAuth)**
- **결정 기준**
  - 타깃이 스레드(Threads) 한국 사용자 → 대부분 카카오 계정 보유, **원탭 로그인**으로 가입 이탈 최소.
  - 지도·로컬 API용 카카오 개발자 앱을 **어차피 등록**하므로 OAuth 추가 설정 한계비용이 작음.

  - 분리 설계: 인증은 @supabase/ssr 세션 위에 얹으므로, A↔B 전환은 provider 설정·로그인 버튼만 교체(앱 로직 불변).

- **지연 시 영향**: 인증(B1) 지연 → 모든 보호 라우트·RLS 검증 지연. 단 전환 비용이 낮아 리스크는 중간.
- **대비**: 카카오 OAuth 비즈앱 심사 등으로 막히면 즉시 매직링크(+커스텀 SMTP)로 폴백.

## #6. 🚨 장소 정보 저장 출처 — 카카오 로컬 API 약관 위반 해소 (✅ **최종 확정 2026-10-26: 사용자 입력 상호명 + 카카오 실시간 검색**)

> **최종 결정**: 아래 (4). SPEC(2026-10-26 전면 개정)의 §0·§1·§2·§3·§4에 반영. `poi_places`·공공데이터 적재는 **폐기**(아래 (1)에서 전환).
>
> **저장 규칙**: DB에 들어가는 카카오 출처 필드는 **0개.**
> - 상호명 = **사용자 입력**(검색 결과로 자동완성하되 사용자가 수정·확정 → 사용자 콘텐츠)
> - region_code = **우리 Turf 판정**(좌표는 판정 후 폐기, 저장 X)
> - kakao_place_id / kakao_url = 약관상 **저장 허용 필드**라 중복감지·딥링크용으로만 선택 저장
> - 좌표·주소 = **저장 안 함**
> - 카카오 로컬 키워드 검색 = **실시간 프록시**로만(응답 미저장, 약관상 실시간 이용 허용)

- **문제(확인됨)**: 카카오 운영자 공식 답변상 로컬 API 응답의 **장소명·카테고리·주소·좌표를 저장하면 약관 위반**(비공개 개인 기록도 불가). 허용은 place_id + 카카오맵 URL + 실시간 표시뿐.
- **검토한 선택지(시간순)**
  - (1) 공공데이터(LOCALDATA) 전환 — 깨끗하지만 전국 POI 적재(100만 행)·DB 용량·커버리지 부담. 지도까지 카카오를 빼니 과한 무게 → 폐기.
  - (2) place_id만 저장 + 실시간 재조회 — 카카오는 **id로 상세조회 엔드포인트가 없음** → 불가.
  - (3) 좌표를 사용자 제공분으로 분리 — 방향은 맞으나 상호명 문제 미해결.
  - (4) **(채택) 상호명을 사용자 입력으로.** 상호명이 사용자 콘텐츠가 되어 저장 가능. 좌표는 판정에만 쓰고 폐기, 주소는 저장 안 함(불필요 — region_code가 시군구를 줌). 지도는 우리 폴리곤. → 저장 필드 중 카카오 출처 0개.
- **잔여 리스크(수용)**: 검색 결과로 상호명을 **자동완성**하면, 사용자가 수정 없이 저장할 때 "사용자 콘텐츠"라는 해석이 100% 깨끗하진 않음(회색). 비공개·개인 일기 수준이라 실질 리스크 낮다고 판단, **수용**. 완전 결벽을 원하면 자동완성을 끄고 수기 입력만.
- **부수 효과(의도)**: ① 좌표 미저장 → **개별 가게 마커 불가**(MVP는 choropleth만), **자동 재판정 불가**(경계 패치는 베타 전 완료). ② 카카오 **지도 쿼터 소멸**(타일 미사용), 검색 쿼터만 — 기록 추가 시에만 호출되어 1인 베타엔 미미.
- **#1에 미치는 영향**: 자체 Turf 판정(#1-A) 확정. 카카오 coord2regioncode 경로(#1-B)는 완전 폐기.
